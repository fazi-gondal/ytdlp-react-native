# Security Policy

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

Report them privately by email to the maintainer at
[huzzat2@gmail.com](mailto:huzzat2@gmail.com). Include:

- the affected package version
- a description of the vulnerability
- steps to reproduce (if available)
- any proof-of-concept code

You will receive an acknowledgment within 5 business days, and a fix will be
coordinated before the vulnerability is disclosed publicly.

## Scope

This policy covers the `ytdlp-react-native` package and its example application.
The embedded third-party components (`yt-dlp-android`, yt-dlp, Chaquopy,
Python) have their own security policies and distribution channels.

## Responsible disclosure

- Do not use this library to access unauthorized or private content.
- Do not use this library to circumvent DRM or authentication.
- Never share cookies, authorization headers, or private URLs in public
  issues.
